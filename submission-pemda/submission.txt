Deskripsi Proyek
----------------
Proyek ini adalah ETL pipeline sederhana yang mengambil data produk
dari website https://fashion-studio.dicoding.dev, membersihkan data,
dan menyimpannya ke dalam file CSV.

Struktur Proyek
---------------
submission-pemda/
├── tests/
│   ├── __init__.py
│   ├── test_extract.py
│   ├── test_transform.py
│   └── test_load.py
├── utils/
│   ├── __init__.py
│   ├── extract.py
│   ├── transform.py
│   └── load.py
├── main.py
├── requirements.txt
└── submission.txt

Cara Menjalankan
----------------
1. Install dependencies:
   pip install -r requirements.txt

2. Jalankan ETL pipeline:
   python main.py

3. Jalankan unit test dengan coverage:
   python -m pytest tests/ -v --cov=utils --cov-report=term-missing

Catatan
-------
- ETL pipeline mengambil data dari seluruh 50 halaman website.
- Harga dikonversi dari USD ke IDR dengan kurs Rp16.000.
- Kolom timestamp ditambahkan pada saat ekstraksi.
- Setiap fungsi dilengkapi dengan error handling.
- Test coverage: 80% (Advanced tier).
